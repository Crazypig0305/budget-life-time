## 設定要花多少時間？

我特地計時了。

1. 搜尋「Honeygain」、進[官網](https://www.honeygain.com/)、點下載：1 分鐘
2. 下載安裝（電腦版）：2 分鐘
3. 建立帳號、填資料、驗證信箱：3 分鐘
4. 啟動程式、確認狀態為 Running：2 分鐘

合計 **8 分鐘**，比我預期快。

啟動後它在背景跑，不需要再做任何事。偶爾確認程式有沒有自己停掉（更新後有時需要重開），每週開電腦的時候瞄一眼，加上那 2 秒，每週維護時間不到 1 分鐘。

## 三個月的實際收益

跑了三個月，沒有特別優化（沒用行動熱點擴增流量，就一台桌機在家放著）。

| 月份 | Credits | 折 USD |
|---|---|---|
| 第一個月 | 1,100 點 | $1.10 |
| 第二個月 | 1,500 點 | $1.50 |
| 第三個月 | 1,500 點 | $1.50 |
| **三個月合計** | **4,100 點** | **$4.10** |

Honeygain Credits 換算：10 Credits = $0.01 USD（[Honeygain 官方出金說明](https://honeygain.com/blog/paypal-payouts-step-by-step-instructions)），4,100 點 = $4.10 USD。

台灣的 IP 在 Honeygain 平台上需求量不如美國、歐洲高，流量共享機會比較少，每月賺到的 Credits 相對偏低。根據 2026 年台灣用戶實際反映，月均約 $1–3 USD，我這三個月平均 $1.37 USD 在正常範圍內。

## 出金怎麼操作？2026 年更新

Honeygain 目前有兩種出金方式：

**標準模式（PayPal）**
- 最低出金門檻：$20 USD（20,000 Credits）
- 以我的月均 $1.37 計算，約需 **14–15 個月**才能第一次出金
- 出金流程：後台按 Request Payout → 收 Honeygain 付款處理商 Tipalti 寄來的邀請信、註冊並填 PayPal 信箱 → 官方說明通常 2 個工作天內入帳（[Honeygain 官方出金說明](https://honeygain.com/blog/paypal-payouts-step-by-step-instructions)）

**JumpTask 模式（收益轉到 JumpTask 平台再出金）**
- 開啟後，收益會轉到 JumpTask 平台，以點數計，1,000 點＝US$1；US$0.50 起就能出金，可以換 PayPal、禮品卡或加密貨幣（[Honeygain 官方 JumpTask 模式說明](https://www.honeygain.com/jumptask-mode/)）
- 開啟後另有 +10% 加成（[Honeygain 官方部落格](https://www.honeygain.com/blog/honeygain-and-jumptask-over-a-year-of-thriving-friendship)，2026 年 3 月的文章，沒寫截止日，以後台顯示為準）
- 開法三步：在 Honeygain 後台右上角按錢包切換鈕 → 註冊一個 JumpTask 帳號 → 把 JumpTask 帳號同步回 Honeygain

怎麼選：兩種都能領到 PayPal，差別在流程。標準模式只用 Honeygain 一個帳號，但要等累積到 US$20；JumpTask 模式要多註冊一個 JumpTask 帳號，出金改在 JumpTask 平台操作，換來的是 US$0.50 就能領。想早點拿到第一筆錢的人，開 JumpTask 模式；不想多管一個帳號、能等一年多的，用標準模式。

## 時薪怎麼算？電費成本一定要算進去

這個工具的時薪計算有點特別：設定時間很短，之後幾乎不需要時間，但電費是持續的成本。

**只算設定時間的時薪（最樂觀版）：**

- 設定 8 分鐘 = 0.133 小時
- 三個月賺 $4.10 USD
- 時薪：$4.10 ÷ 0.133 = **$30.8 USD/hr**（約 NT$955）

這個數字聽起來不錯，但這是把三個月的收益全部算在 8 分鐘上的結果。真正的成本不只是時間。

**加上電費之後的真實計算：**

| 項目 | 數字 |
|---|---|
| 桌機功耗 | 約 80W |
| 三個月跑 24 小時 | 90 天 × 24 小時 = 2,160 小時 |
| 總用電量 | 2,160 × 0.08 kWh = 172.8 度 |
| 台灣電費（夏天用電段） | 約 NT$4.7/度 |
| 三個月電費 | 172.8 × 4.7 ≈ **NT$812** |
| 三個月累積 | $4.10 USD ≈ **NT$127** |
| 收益 − 電費（電腦專為它開著時）| 約 −NT$685 |

如果整台電腦是為了 Honeygain 專門開著，三個月電費比收益多出約 NT$685。

**這個發現讓我改變了使用方式：** 電腦本來就要開著的時候，讓 Honeygain 在背景跑。不要為了 Honeygain 特地讓電腦開著。

## 哪種情況值得裝？哪種情況建議跳過？

{{< skip-box title="裝之前先對照：這幾種情況要換個做法" >}}
- **電腦平常很少開**：收益只在電腦開著時才累積，為它特地開機的話，上面算過電費會比收益高。改裝在家裡本來就長時間開著的那台，不要為它另外開機。
- **等不了 14–15 個月才出第一次金**：改開 JumpTask 模式，US$0.50 就能出金（見上方出金段）。
- **在意 IP 與資安**：Honeygain 是拿你的 IP 和頻寬讓別人的流量經過。[Cisco Talos 2021 年的研究](https://blog.talosintelligence.com/proxyware-abuse/)指出兩件事：網路上有假冒 Honeygain 的安裝檔夾帶惡意程式；經過你網路的流量，對外看起來是從你這邊發出去的。降低風險的做法：只從官網下載安裝檔；裝在沒有工作資料、沒有機密檔案的電腦；公司網路或跟家人共用的工作電腦上不要裝。
{{< /skip-box >}}

**適合繼續裝的情況：**

- 電腦原本就長時間開著（工作、遊戲、或放著當伺服器）——電費成本不額外增加
- 接受收益很小、長期累積才出金的節奏
- 不會「追績效」，裝了就忘，幾個月看一下帳戶

## 自己算：你的情況值不值得？

下方是一個 ROI 試算表，把你的情況填進去，讓你決定要不要裝。

{{< budget-table title="Honeygain 個人 ROI 試算" sub="填入自己的數字，判斷值不值得" >}}
| 項目 | 範例值 | 你的情況 |
|---|---|---|
| 每月實際用機時數 | 120 小時（平日 5hr + 假日 3hr × 30 天）| ＿＿ 小時 |
| 台灣用戶月均收益估計 | $1.5 USD（中間值）| ＿＿ USD |
| 電腦功耗 | 80W（桌機）/ 30W（筆電）| ＿＿ W |
| 月電費成本（P × hr × $4.7/1000）| 80W × 120 × 4.7/1000 ≈ NT$45 | ＿＿ NT$ |
| 月收益折台幣（× 31）| $1.5 × 31 ≈ NT$47 | ＿＿ NT$ |
| **月淨收益（收益 - 電費）** | **NT$2（幾乎打平）** | **＿＿ NT$** |
| 你的時薪目標門檻 | NT$196（2026 最低工資）| ＿＿ NT$/hr |
| 折算月維護時薪（月收益 ÷ 月維護分鐘）| NT$47 ÷ 5 min ≈ NT$564/hr | ＿＿ NT$/hr |
{{< /budget-table >}}

**怎麼看這個表：**

- **月淨收益 > 0**：收益大於電費，裝著合理。
- **月淨收益 < 0**：電費比收益高，不值得特地開機。
- **折算月維護時薪 > 你的門檻**：時間投入合理，但注意每月實際收益很小，能接受才裝。

## 三個月後我的狀態

繼續讓它在背景跑，但我已經幾乎忘記它的存在了。每次想到才打開看一下，不主動管它。

它的使用方式就應該是這樣：不期待、不追、設好就讓它跑，某天帳戶裡多一點就看到了。期望不要設太高，月均 $1–2 USD 就是台灣用戶的現實，拿它當「電腦反正在開著、多賺一點閒錢」，而不是當作固定收入來源。

電腦本來就長時間開著的人，今天花 8 分鐘從官網裝好，一個月後打開後台看一次 Credits；想早點拿到第一筆錢，就順手切成 JumpTask 模式。電腦平常不常開的人，換成家裡本來就長開的那台來裝，不要為它特地開機。
